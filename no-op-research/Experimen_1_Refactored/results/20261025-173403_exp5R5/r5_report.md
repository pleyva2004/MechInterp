Topology reused from `exp4/tda4_graph.py` (`dist`, `summarize`, `persistent`, `rep_cycle`, `_arcs`) with TDA 4's thresholds (persist_min 0.002, persist_ratio 0.75, stable ≥ 0.8, absent ≤ 0.2). BOS node removed. 1000 row bootstraps per filler (same resamples for every τ, layer, kind and condition).

Graph kinds: **raw** = mean over heads of attention; **vw** = Σ_h A_h[q, k] · ‖v_k W_O^h‖, each query row divided by its sum (BOS and diagonal included) per data row, then averaged (primary); **vwM** = vw averaged over rows, then row-normalised; **vwU** = vw un-normalised, divided by a per-(filler, layer) constant c (mean row sum of the capital controls), clipped at 1. MPC (matching-pair cycle) = a persistent H1 class whose representative cycle uses the edge {32, τ}.

## Caveats

- The same 11 country–capital pairs throughout; rows are resampled, pairs are not. A bootstrap frequency says the loop is consistent over these rows and pairs, not that it generalises to other pairs.
- Topology of the mean graph (over rows × 11 cells), not of each sequence's attention.
- Folded bias: TransformerLens folds each head's constant value term (β_ln1 W_V + b_V) W_O into b_O. The value norms ‖v_k W_O^h‖ exclude it, so vw measures the key-dependent part of each head's write. Attention rows sum to 1, so the folded part is added whatever the head attends to and carries no routing information, but ‖(v_k + b_V) W_O‖ ≠ ‖v_k W_O‖, so vw is not the norm of the full write. The writing weights are also mean-centred (TL default).
- Norms ignore direction: Σ_k A_k ‖v_k W_O‖ ≥ ‖Σ_k A_k v_k W_O‖, and writes from different keys or heads can cancel. The vw graph is an upper bound on the norm actually moved along each route.
- vw sums heads (raw averages them); row normalisation makes both have unit row sums, so the filtrations are on the same [0, 1] scale. vwU keeps each query's total write but its scale constant is a choice.
- The persistence thresholds were calibrated on raw attention in TDA 4; vw weights on non-BOS keys are larger (the BOS share drops), so the absolute floor (0.002) is easier to clear; the ratio rule is scale-free.
- Per-row graphs are stored in fp16; normalisation and filtrations are computed in float64.
- Own and wrong graphs differ only in query row 32 (checked), so every own-vs-wrong topological difference is about how node 32 attaches to a fixed graph; under vw the normaliser of row 32 also depends on the capital's own value norm (the diagonal), which differs between own and wrong from layer 1 on.
